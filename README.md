# 绿色贸易与低碳学习导航

这是一个基于纯 HTML/CSS/JavaScript 的静态网站，聚合了绿色贸易、低碳转型、ESG 合规、碳核算与政策解读相关的学习资料、课程、标准和法规资源。

项目内容主要包括：

- 9 周学习路线图
- 绿色贸易 / 低碳 / 碳中和基础知识导图
- 国内外权威标准与政策资源链接
- 公开课 / 慕课学习建议
- 专业书籍与官方解读入口
- ESG、CBAM、ESPR、ErP、CSRD 等法规学习资料

## 项目定位

这个页面适合：

- 想系统学习绿色贸易、低碳发展相关知识的人
- 需要梳理碳核算、ESG、LCA 等主题学习路径的人
- 关注欧盟法规与中国双碳政策的人
- 需要快速查找标准、课程、资料入口的学习者

## 页面内容结构

项目主体文件为：

- `index.html`：完整页面内容，包含全部学习路线和资源模块
- `README.md`：项目说明文档

页面主要包含以下几部分：

1. 学习周计划
2. 公开课 / 慕课推荐
3. 标准 PDF 下载与资源入口
4. 专业书籍推荐
5. 官方解读与政策文档
6. 知识框架和获取指南

## 运行方式

由于本项目是纯静态页面，无需安装依赖，可以直接在浏览器中打开：

```bash
# 直接打开 index.html
open index.html
```

或者使用本地 HTTP 服务预览：

```bash
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

## 预览效果

打开 `index.html` 后，页面会展示：

- 顶部概览信息
- 分阶段学习路线
- 课程与标准资源卡片
- 标签式导航切换
- 适配移动端与桌面端的页面布局
